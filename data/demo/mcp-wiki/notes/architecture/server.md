# Server

A server provides context and capabilities: [[tools]], [[resources]], [[prompts]]. Servers advertise themselves via [[server-discover]] and declare [[capabilities]]. Remote servers are protected resources in [[authorization]]; local ones typically use [[stdio-transport]].
