# Extensions

Optional, opt-in modules negotiated through the `extensions` field of capabilities. Notable: [[tasks-extension]], [[skills-over-mcp]], [[mcp-apps]]. Auth extensions live in a separate ext-auth repository ([[authorization]]). See [[capabilities]].
