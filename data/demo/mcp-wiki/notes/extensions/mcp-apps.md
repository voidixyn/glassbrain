# MCP Apps

Extension (`io.modelcontextprotocol/ui`, SEP-1865) letting servers ship interactive UIs: `ui://` resources of HTML rendered in a sandboxed iframe by the host, linked to tools via metadata, with two-way JSON-RPC to the host. Supporting clients reportedly include Claude, ChatGPT, VS Code and Goose. See [[resources]], [[tools]], [[extensions-overview]].
