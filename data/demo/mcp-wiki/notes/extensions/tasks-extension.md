# Tasks extension

Asynchronous long-running operations (`io.modelcontextprotocol/tasks`). Experimental in 2025-11-25, moved out of core in 2026-07-28: polling via `tasks/get`, `tasks/update` for client input, no `tasks/list`, and servers may return task handles unsolicited. See [[extensions-overview]], [[progress]], [[spec-2026-07-28]].
