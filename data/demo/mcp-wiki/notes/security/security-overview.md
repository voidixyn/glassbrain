# Security overview

Principles from the spec: user consent and control, data privacy, tool safety. The protocol cannot enforce them, so hosts must. Threat notes: [[tool-poisoning]], [[rug-pull-and-shadowing]], [[indirect-prompt-injection]], [[confused-deputy]], [[dns-rebinding]]. Mitigation: [[human-in-the-loop]], [[authorization]].
