# Deprecated features

Deprecated in 2026-07-28 but still functional: [[roots]], [[sampling]] and [[logging]] (SEP-2577); the [[http-sse-legacy-transport]]; `includeContext` values thisServer/allServers; Dynamic Client Registration (in favor of [[client-id-metadata-documents]]). Governed by [[feature-lifecycle-policy]].
