# Error codes

Resource not found changed from -32002 to -32602. Policy: -32000..-32019 implementation-defined, -32020..-32099 reserved for MCP. Allocated: HeaderMismatch -32020, MissingRequiredClientCapability -32021, UnsupportedProtocolVersion -32022. See [[mcp-http-headers]], [[protocol-versioning]], [[tool-errors]].
