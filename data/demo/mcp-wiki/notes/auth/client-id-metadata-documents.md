# Client ID Metadata Documents

The client uses an HTTPS URL as its client_id; the authorization server fetches a JSON metadata document from it and validates redirect URIs. Recommended since 2025-11-25 and preferred over DCR in 2026-07-28. See [[client-registration]], [[authorization]].
