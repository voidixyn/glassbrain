# Client registration

Clients get a client ID through Client ID Metadata Documents, pre-registration, or Dynamic Client Registration (RFC 7591, now Deprecated). Credentials are bound to the issuing authorization server and must be re-registered if it changes. See [[client-id-metadata-documents]], [[authorization]].
